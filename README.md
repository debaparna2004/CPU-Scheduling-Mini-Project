CPU Scheduling Algorithms in C++

This project implements basic CPU Scheduling Algorithms used in Operating Systems using C++.

Algorithms Included
First Come First Serve (FCFS)
Shortest Job First (SJF)
Round Robin (RR)
Features
Calculates Waiting Time
Calculates Turnaround Time
Displays Average Waiting Time
Displays Average Turnaround Time
Menu Driven Program
Technologies Used
C++
Basic OS Scheduling Concepts

Concepts Used
Process Scheduling
Queue Management
Waiting Time Calculation
Turnaround Time Calculation
Time Quantum in Round Robin

Purpose
This project was created to understand the working of basic CPU Scheduling Algorithms in Operating Systems and their effect on process execution time.
